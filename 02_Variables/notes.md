# Variables

## Topics Covered

- Variable Declaration
- Multiple Variable Assignment
- Line Continuation
- Printing Variables
- String Concatenation
- String Repetition

## Key Points

- Variables store data in memory.
- Multiple variables can be assigned in one line.
- Use `\` or parentheses `()` to continue long statements.
- `+` concatenates strings.
- `*` repeats strings.
- Avoid naming variables after built-in functions (e.g., `sum`, `list`, `str`).
