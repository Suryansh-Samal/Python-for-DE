# Sets

## Topics Covered

- Set Creation
- Empty Set
- Duplicate Removal
- Union
- Intersection
- add()
- remove()

## Common Set Methods

| Method | Description |
|---------|-------------|
| `add()` | Adds an element to the set |
| `remove()` | Removes the specified element |
| `union()` | Returns all unique elements from two sets |
| `intersection()` | Returns common elements between two sets |

## Key Points

- Sets store **unique** values.
- Duplicate values are automatically removed.
- Sets are unordered, so the output order may vary.
- Use `set()` to create an empty set. Using `{}` creates an empty dictionary.
