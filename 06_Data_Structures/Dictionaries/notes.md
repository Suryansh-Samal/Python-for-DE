## Common Dictionary Methods

| Method | Description |
|---------|-------------|
| `keys()` | Returns all dictionary keys |
| `values()` | Returns all dictionary values |
| `items()` | Returns all key-value pairs |
| `pop(key)` | Removes the specified key and returns its value |

## Key Points

- Dictionaries store data as **key-value pairs**.
- Keys must be unique.
- Dictionaries are mutable, meaning values can be updated after creation.
- Nested dictionaries allow storing dictionaries inside other dictionaries.
