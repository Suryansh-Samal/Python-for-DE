# Tuples

## Topics Covered

- Tuple Creation
- Tuple Indexing
- Tuple to List Conversion
- append() after Conversion

## Key Points

- Tuples are **ordered** collections.
- Tuples are **immutable**, meaning their elements cannot be changed after creation.
- Elements can be accessed using indexing.
- To modify a tuple, convert it to a list using `list()`.
- Lists can then be modified using methods like `append()`.
